🏈 Live NFL Scoreboard

How it works:
• Place this action on as many keys as you want — each key is one game
• Shows this week's games (Thursday through Monday) in kickoff order
• Live games show possession and the red zone, flash on every score, and show the play (TD +6, XP +1, FG +3, SAF +2, 2PT +2)
• Keys refresh every 30 seconds (every 15 in the two-minute warning)
• Press any key to open that game in ESPN Gamecast (the box score once it's final)
• More games than keys? The last key shows +N more
• These settings apply to all scoreboard keys
A full NFL week has up to 16 games — a Stream Deck XL (32 keys) or a Virtual Stream Deck fits the whole week. Each Stream Deck you use gets its own board, starting from game 1.

Want just one team? Use the Live NFL Scores action instead.
